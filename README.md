## 🛠️ 寄件前设备准备清单 (Pre-Shipping Checklist)

在打包寄出您的 Mac mini M4 之前，请务必完成以下 4 步，否则设备抵达后将无法正常初始化上架：

- [ ] **1. 彻底解除 Apple ID 与激活锁（极其重要）**
  * 请进入 `系统设置` -> 退出您的 Apple ID，确保关闭 **“查找我的 Mac (Find My)”**。
  * 登录您的 iCloud 网页端或手机端，将该台 Mac mini 从设备列表中**彻底移除**（确认 `Activation Lock` 状态为 `Disabled`）。
  * *注：带有激活锁的设备一旦系统崩溃将无法在机房端进行 DFU 恢复，机房拒收未解绑激活锁的设备。*
- [ ] **2. 恢复出厂设置（可选）**
  * 建议执行“抹掉所有内容和设置”，或保留一个无重要隐私数据的初始管理员账号，并在工单中告知开机密码以便工程师配置远程网络。
- [ ] **3. 精简寄送配件（减轻首重）**
  * **仅需寄送：Mac mini 主机裸机 + 原装八字电源线**。
  * 国行 Mac mini 内置 100V-240V 全球宽幅电源且双扁插头与加拿大插座完全兼容，无需附带转换插头，**请勿寄送显示器、键盘、鼠标或网线**。
- [ ] **4. 严密防震包装与身份标识**
  * 请使用原厂包装盒，并在盒外缠绕至少 3 层加厚气泡柱/泡沫箱以防跨国暴力分拣。
  * 请在 Mac mini 机身底部贴上一张纸条，清晰写明您的 **【MacHub 订单号 / Telegram 或 WhatsApp 联系方式】**，以便机房拆包后第一时间核对身份。
